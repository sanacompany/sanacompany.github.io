Nalla

Results

  • 01Shipped to App Store and Play Store for the Korean market
  • 02Region search and filtering across the bike-station network
  • 03Statistics module for operational monitoring
  • 04TensorFlow prediction model for slot availability forecasting

Nalla is a mobile app targeted for South Korea. With Nalla you can reserve bikes the smart way. Our client asked us to make major changes to the mobile app and deploy it to both stores (App Store and Play Store).

02

One of the biggest changes was in their Dashboard application, built in React and Django. We added region search and filtering so the client can target bike stations accurately, along with a statistics module to monitor the network.

03

We built a Machine Learning prediction module from scratch using TensorFlow. The model tells the user how many bike slots will be available in the next minutes / hours.
